# MVP, 그다음

[구름 해커톤 특강 HTML 장표](https://smilesjcha.github.io/goorm-mvp-lecture/)

본강의·Q&A 35장, 부록 25장으로 구성된 60장 강의 자료입니다. 블랙·딥블루 디자인의 브라우저 발표, 모바일 읽기, 목차 검색, 발표자 노트와 오프라인 HTML을 제공합니다.

- `index.html`: 온라인 장표
- `goorm-mvp-lecture.html`: 글꼴과 이미지를 포함한 오프라인 장표
- `goorm-mvp-*-v4-20261117.pdf`: 본강의, 부록, 합본 PDF
- `sources.csv`: 출처 76개 및 원본 확인일

방향키로 이동하고, N으로 발표자 노트, F로 전체 화면을 켭니다.

가격은 2026-11-14, 사례·저장소는 2026-11-16 기준의 원본 스냅샷입니다. 상태·데모는 강연용 설계 예시이며 실제 AI 호출을 하지 않습니다. PDF는 HTML에서 직접 생성한 검토본으로 편집 가능한 PPTX가 아닙니다.

이미지 권리와 출처는 `assets/ORIGINS.json`, Pretendard 글꼴의 라이선스는 `assets/fonts/OFL.txt`를 참고하세요. 외부 이미지나 인용 자료의 별도 재사용 권한을 부여하지 않습니다.
