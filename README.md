# MVP, 그다음

[고객이 다시 찾는 AI 서비스 / 구름 해커톤 특강](https://smilesjcha.github.io/goorm-mvp-lecture/)

차성재, AI Engineer 출신 AI PM. 금융·의료·교육·이커머스 산업을 경험했으며 현재 무신사 Core AI PM으로 Agent Chat, GEO, 모두의AI 서비스를 담당합니다. 본강의·Q&A 35장, 부록 25장으로 구성된 60장 HTML 강의 자료입니다.

Seller Studio라는 교육용 커머스 사례로 문제 정의, UI·UX Writing의 AS-IS/TO-BE, 인증·결제·비동기 작업, MCP/API, 서킷브레이커, Claude·Codex 검증, 비용과 포트폴리오를 설명합니다. 블랙·딥블루 발표 화면, 모바일 읽기, 목차 검색, 발표 노트와 오프라인 HTML을 제공합니다.

저장소 소개 7장에는 문장 편집·UI 개선·관리 화면·실행 추적·테스트 재생 등 8종의 실제 공개 화면을 함께 실었습니다. 용도와 Stars, 도입 시 살펴볼 조건, 이미지 출처를 구분해 표시합니다.

- `index.html`: 온라인 장표
- `goorm-mvp-lecture.html`: 글꼴·이미지를 포함한 오프라인 장표
- `goorm-mvp-*-v5-20261117.pdf`: 본강의 35쪽, 부록 25쪽, 합본 60쪽
- `repositories.csv`: 24개 저장소의 용도·Stars·라이선스·최근 push
- `sources.csv`: 50개 공식 출처와 확인일
- `scenarios.csv`: 검증 시나리오 양식

방향키로 이동하고 N으로 발표 노트, F로 전체 화면을 켭니다.

저장소와 문서는 2026-11-17 KST에 확인했습니다. Stars는 관심도 지표이며 품질·보안 보증이 아닙니다. UI 목업·상태 시연·비용 계산은 교육용 가정입니다. 실제 AI 생성, 결제, REA 분석을 실행한 실적으로 제시하지 않습니다. PDF는 HTML에서 직접 생성한 검토본이며 편집 가능한 PPTX가 아닙니다.

실제 공개 화면의 출처는 `assets/cases-v5/ORIGINS.json` 및 `assets/repos-v5/ORIGINS.json`, 이전 이미지의 출처는 `assets/ORIGINS.json`, Pretendard 라이선스는 `assets/fonts/OFL.txt`에 있습니다. 외부 이미지·인용 자료의 별도 재사용 권한을 부여하지 않습니다. 이전 v4 PDF는 기존 링크 보존을 위해 유지합니다.
